# Texture replacement trial (x2, Kokiri Forest)

A local, optional pack of x2 textures, to judge before any full pack. Everything derived from the cartridge stays in git-ignored `out/`; nothing is published (the Pages build copies no pack).

## Hook

- `tools/tex/hash.ts`: name of a decoded texture = 64-bit hash (16 hex digits) of its size and its RGBA8 texels as the interpreter produced them (after the tile's format and palette), shared by the renderer and the tools.
- `web/tex-pack.ts`: fetches `/texpack/index.json` (404 or anything not JSON: no pack) and `/texpack/<hash>.png` on first sight of a hash. `tools/tex/serve.ts` serves `out/texpack/` (or `OOT_TEXPACK_DIR`) from the dev and preview servers to loopback clients only, mapping only `index.json` and `<16 hex>.png`.
- `web/renderer.ts`: a replacement exactly twice the size of its texture is uploaded in its place; the tile's coordinates, origin, shift and mask periods are scaled by 2 in the uniforms, so the shader's wrap, mirror, clamp, filter mode, mip levels and anisotropy apply unchanged. Others stay original. Key **T** (or `localStorage['oot.texpack']='0'`) switches between original and pack; `globalThis.ootTexPack` is the handle the compare tool uses. With the pack off (or absent) the draw is the old path: same upload, scale 1.
- A texture whose pixels change every frame hashes differently each time and gets no entry: it stays original. `dump` reports them (see below).

## Tools (`npm run tex -- <command>`)

- `dump`: plays the scripted new game headless to Link's house under control (frame 19,000), loads Kokiri Forest (entrance 238, 3,000 video frames with A taps for the cutscene, then a stick walk), then the six interior entrances the forest's exit list names (626, 193, 201, 156, 1075, 1079; `docs/re/display-lists.md` section 9), 700 frames each. Writes every unique decoded texture to `out/texdump/<hash>.png`, `index.json` (size, tile format, wrap/mirror/clamp per axis, alpha kind, frames seen, scenes) and `report.json`. Churn rule: a group (size and tile format) is churning when it is drawn in at least 20 graphics tasks and has new pixels in at least half of them; its textures seen in at most 5 tasks are marked volatile and skipped.
- `upscale`: x2 of every non-volatile texture of at most 128 px a side seen in at least 3 tasks. Padding of 16 texels is added first (wrap, mirror or clamp, per axis, from the tiles that sampled it); colour under fully transparent texels is bled from visible neighbours; the model doubles the opaque colour picture; the result is cropped back. Colour = `blend` x model + (1 - `blend`) x plain bilinear x2 (default `--blend 1`; the trial used 0.5). Alpha is upscaled separately: bilinear x2 of the padded alpha, cut at 128 if the texture has only alpha 0 and 255 (cut-outs stay crisp), and transparent texels take the colour of their nearest visible neighbour (no halo). Gray textures stay gray. It checks every wrapping axis against the plain bilinear x2 of the same texture and reports seams. `index.json` of the pack records model, file hashes, settings and runtime.
- `compare`: headless Chrome, game in Kokiri Forest from save state 1 (a copy of the saves folder), six places by held arrow keys; at each the frame is frozen and drawn twice by the page's renderer (original, then pack, then original again to check it returns to the same picture). Writes `out/tex-compare/view-N-*-original.png`, `-pack.png`, 1:1 crops and `index.html` (swipe slider and side by side).

## Model and settings used

Third-party model, run locally, weights not committed: `realesr-animevideov3-x2` from the official release `xinntao/Real-ESRGAN` v0.2.5.0, asset `realesrgan-ncnn-vulkan-20220424-windows.zip` (zip SHA-256 `abc02804e17982a3be33675e4d471e91ea374e65b70167abc09e31acb412802d`), extracted into `~/.zelda-oot-js/tools/realesrgan-ncnn-20220424/`. The model files are read by `tools/tex/model_run.py` (numpy; Python 3.12 venv at `~/.zelda-oot-js/tools/venv` with `numpy` and `pillow`). Why not the release's own executable: its Vulkan build lost the device on the RTX 4060 Ti (`vkWaitForFences failed -4`), and the `ncnn` Python package returned different, partly garbage output on every run of this model; the numpy reader matches the clean ncnn output (mean difference 0.06/255) and is deterministic. This model is not a general-purpose one: it is a compact network for cartoon video; the release's x2 variant is its x4 network followed by a bicubic halving (end of its param file). At full strength (`--blend 1`) it drew ink-like outlines on bark and eyes, so the trial pack mixes it 50/50 with bilinear x2.

Run: `npm run tex -- dump && npm run tex -- upscale --blend 0.5 && npm run tex -- compare`.
